# Sayanz Store
نسخة البداية لمتجر ساينز ستور.

الملفات:
- index.html: الصفحة الرئيسية
- style.css: التصميم
- script.js: المنتجات والسلة

ملاحظة: الدفع الحقيقي عبر Mastercard ولوحة تحكم الطلبات لم يتم ربطهما بعد، وسنضيفهما في الخطوات التالية.

المرحلة الثانية: checkout + Mastercard كخيار + حفظ الطلبات محليًا + admin.html. هذا نموذج أولي فقط وليس دفع Mastercard حقيقيًا أو قاعدة بيانات سحابية.
